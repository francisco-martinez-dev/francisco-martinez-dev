# 💳 FinTrack — Panel de Transacciones

Aplicación web para el registro y visualización de transacciones financieras personales, desarrollada con HTML, CSS y JavaScript vanilla.

## 🖥️ Vista previa

![Panel mostrando saldo, gráfica de movimientos e historial de transacciones](preview.png)

## ✨ Funcionalidades

- Registro de depósitos, retiros y transferencias
- Saldo actualizado en tiempo real
- Alerta automática cuando el saldo baja de $100.00
- Gráfica de tendencia de los últimos movimientos
- Historial filtrable por tipo de transacción
- Persistencia de datos con localStorage

## 🛠️ Tecnologías

- HTML5
- CSS3 (Grid, Flexbox, diseño responsivo)
- JavaScript vanilla (Canvas API, localStorage, DOM)

## 🚀 Cómo usar

1. Cloná el repositorio
2. Abrí `index.html` en tu navegador
3. Registrá una transacción seleccionando el tipo, descripción y monto
4. El panel actualizará el saldo, gráfica e historial automáticamente

## 💡 Características técnicas

- Los datos persisten entre sesiones gracias a localStorage
- La gráfica muestra los últimos 7 movimientos con puntos de color según tipo
- Los filtros del historial permiten ver solo depósitos, retiros o transferencias
