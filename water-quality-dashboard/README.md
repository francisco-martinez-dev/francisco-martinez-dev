# 💧 Water Quality Dashboard

Panel interactivo para el monitoreo de contaminantes en fuentes de agua de El Salvador, desarrollado con HTML, CSS y JavaScript vanilla.

## 🖥️ Vista previa

![Dashboard mostrando gráfica de contaminantes con indicador de precaución](preview.png)

## ✨ Funcionalidades

- Registro de muestras por ubicación y fecha
- Visualización de niveles de arsénico, plomo y mercurio
- Gráfica de barras con líneas de límite según estándares OMS
- Indicador de riesgo automático (seguro / precaución / peligro)
- Historial de muestras registradas

## 🛠️ Tecnologías

- HTML5
- CSS3 (Grid, variables, diseño responsivo)
- JavaScript vanilla (Canvas API, DOM)

## 🚀 Cómo usar

1. Cloná el repositorio
2. Abrí `index.html` en tu navegador
3. Ingresá una muestra con ubicación, fecha y niveles de contaminantes
4. El dashboard actualizará la gráfica e indicador automáticamente

## 📊 Límites de referencia (OMS)

| Contaminante | Límite máximo |
|---|---|
| Arsénico | 10 µg/L |
| Plomo | 10 µg/L |
| Mercurio | 6 µg/L |
